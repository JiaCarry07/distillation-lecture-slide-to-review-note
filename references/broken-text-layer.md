# PDF 文字层错乱时

`extract_pdf_text.py` 的“高频中文字命中 0 次”只是提示。先挑 2–3 页，把抽出的文本和 PDF 页面目视对照；有些课件字少或以英文、公式为主，也可能得到 0。只有确认中文出现乱码、缺字或公式碎裂时，才转为读图。

用随包脚本渲染需要核对的页面：

```powershell
python build\rasterize_pdf_pages.py .\src\chapter1.pdf .\qa\chapter1 --pages 1,3-8 --dpi 150
```

它输出 `page-0001.png` 等文件。逐页读取图片，记录页码、标题、公式、图示、例题条件和答案；不清楚的符号回到原 PDF 放大核对。若有可靠的本地 OCR，可把 OCR 当初稿，但仍要对照图片校正。不要猜测缺失的指数、上下标、极性或题目数值。

本包没有自动 OCR，也不包含其他 skill 的脚本。内容确认后，再按 `SPEC.md` 写 `chNN.html`。原课件与核对图片留在工程目录，最终公开仓库只放获准公开的自编示例。
